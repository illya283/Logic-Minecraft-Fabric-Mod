LOGIC — исходный проект Fabric
================================

Что есть:
- предмет «Катана Logic» с красно-чёрной пиксельной текстурой;
- при использовании — красные/магические частицы;
- исходный код и ресурсы.

ВАЖНО:
Это исходный проект, а не готовый .jar. Сборка для Minecraft 26.3 экспериментальная и
не проверена в этой среде. Версии Fabric API / Loom могут потребовать обновления.
Сам предмет пока НЕ бросается и не имеет полноценной анимации взмаха.

Как собрать (Windows):
1. Установи JDK 25.
2. Установи IntelliJ IDEA Community.
3. Распакуй ZIP в папку без кириллицы, например C:\MinecraftMods\logic_mod.
4. Открой папку logic_mod через IntelliJ IDEA.
5. Дождись синхронизации Gradle.
6. В терминале проекта выполни: gradle build
7. Если сборка успешна, файл будет в build\libs\logic-1.0.0.jar
8. Положи .jar в папку mods профиля Fabric, вместе с Fabric API.

Если команда gradle не найдена:
Открой Gradle tool window в IntelliJ IDEA и запусти Tasks > build > build.

Если возникнет ошибка:
Пришли скриншот или весь текст ошибки. Не покупай кредиты на сайтах ради этого проекта.
